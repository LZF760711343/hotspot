热点收集助手 - 使用说明
================================

【怎么运行】
双击 dist 文件夹里的「热点收集助手.exe」即可。
程序会在后台启动，并自动打开浏览器进入管理界面（网址 127.0.0.1:56789）。
没有自动弹出的话，手动在浏览器打开 http://127.0.0.1:56789
要退出程序：在任务管理器里结束「热点收集助手.exe」进程。

【能做什么】
1. 关键词搜公众号文章（顶部卡片）：输入关键词和要多少篇（默认20），点「搜索公众号」。
   会按相关度搜出公众号文章，显示标题、公众号名、摘要和原文链接，勾选后收藏。
   说明：公众号文章没有公开的阅读量，这里是按搜索相关度排序，用 #1 #2… 序号表示。
2. 抓取公开热榜：选择榜单，点「抓取并预览」。抓到的条目默认全部勾选，
   取消勾选不需要的，再点「收藏选中 (N)」只把选中的入库——不用事后再去列表里删。
   还有「全选 / 全不选」按钮可快速操作。
   内置 6 个榜单：
   · 公众号热文榜(按阅读量)——微信24h热文，按阅读量从高到低排列，每条带阅读量和原文链接
   · 微博热搜、百度热搜、夸克热点、知乎热榜、抖音热榜
3. 管理：下方列表支持搜索、编辑、删除、清空。
4. 润色文本（重点）：收藏列表里直接点标题，会弹出「润色」框，显示这条的原文
   （标题+备注+来源），可以：
   · 直接在编辑区改文字，右边实时预览，满意后点「复制文本」拿走；
   · 用本地排版工具：整理文案 / 去空行 / 加序号 / 加项目符号 / 标题加粗 / 还原原文；
   · 点「✨ AI 润色」让大模型智能改写（需先配置，见下）。
   标题旁边保留「🔗原文」小链接，需要看原始网页时可以点开。

【AI 润色怎么配】
点润色框里的「AI 设置」，最上面是「🆓 免费模型优先」下拉，免费模型排在最前：
  1. 智谱 GLM-4-Flash —— 永久免费（推荐，中文写作好）
  2. 通义千问 Qwen-Turbo —— 新用户送免费额度
  3. DeepSeek Chat —— 低价/有免费额度
  4. 自定义 —— 任何 OpenAI 兼容接口
选一个会自动填好「API 地址」和「模型名」，你只需到对应平台申请一个 Key 填进
「API 密钥」，点「保存配置」即可。密钥只存本机 config.json，不上传。
（免费政策会变，以各平台官网实时为准。）

【目标字数 / 扩写】
润色框中部有「🎯 目标字数」数字输入：
- 填 0 = 不限字数；
- 填比如 500 = AI 润色时会把内容扩写/压缩到 500 字左右，不偏离原意。
手动编辑和本地排版工具不受这个数字影响，只有「AI 润色」会用它。

说明：这个 exe 是脱离 WorkBuddy 平台独立运行的单机程序，无法直接使用 WorkBuddy
账号内的免密钥模型通道（那需要发布在 WorkBuddy 平台的应用身份）。因此采用"预置
免费模型 + 填各平台免费 Key"的方式，效果一样：零成本用上免费大模型。

【数据存在哪】
所有数据保存在本机： C:\Users\Design\热点收集助手数据\hotspots.db
卸载时删掉这个文件夹即可，不写注册表、不联网上传。

【注意】
- 出现"连接不上服务，请重新双击 exe"怎么办：说明后台服务没在运行（exe 进程被关掉了）。
  重新双击 exe 启动即可，浏览器已开的页面刷新一下就能用。
- 抓取依赖公开 API，有请求频率限制。若提示"被限流"，稍后再试或换一个榜单即可，
  不影响手动录入功能。
- 首次运行 exe 可能需要几秒解压，请耐心等待浏览器弹出。

【源码与重新打包】
app.py 是后端，templates/index.html 是界面。
改完代码后运行： python build.py 可重新生成 exe。
